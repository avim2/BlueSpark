BlueSpark
=========

Tekken Tag Tournament 2 for the Xbox 360, running natively on Windows. It has rollback netcode, ranked
matches with a leaderboard, and a training mode built after Tekken 8's.

This is a play test, so expect bugs.

This repository holds the builds and the small file that Start Here reads to find updates. There are no
game files here, and there never will be. You build the game on your own PC from your own copy of TTT2.


What you need
-------------

- Windows 10 or 11, 64-bit, with a DirectX 12 graphics card.
- Your own copy of TTT2: an image of your disc, or default.xex and the data*.bin files in one folder.
  It must be title 4E4D0859.
- The game's title update 0.0.3.2, from your Xbox 360's hard drive (a file named like
  TU_174Q22P_0000008000000.00000000000O2).
- About 7 GB of free space.
- A controller or a keyboard.


Getting started
---------------

1. Download the newest zip from the builds folder, or use the one you were given.
2. Unzip it to a short path, for example C:\ttt2.
3. Double-click Start Here and click the steps in order: Install tools, Choose my game + update,
   Build the game. Then Play TTT2, or Play BlueSpark (the fast client: Ranked, lobbies, training and
   replays in one window, with the game kept ready behind it). Both play the same game: players on
   either one meet each other online.

The README.txt inside the zip explains each step, where to find your game files, the controls and
what to do if something goes wrong.


Updates
-------

Start Here checks this repository every time you open it. When a newer build is listed here, it
downloads it, checks that it's ours, puts it over your folder and rebuilds. Your saves and settings
are kept.

You can also update by hand: drag a new zip onto the open Start Here window.

Start Here only installs builds signed by us. A zip from anywhere else is refused.
